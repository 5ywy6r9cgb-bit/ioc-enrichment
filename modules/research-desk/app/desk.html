The clock

Ohio R.C. 149.43 sets no fixed day count — inspection is "promptly," copies come "within a reasonable period of time." Every Ohio day-number in this system is your follow-up cadence, not a statutory deadline, and the deadline_rules.rule_basis column records which is which so the distinction can never quietly blur.

The standard — GlassMark

A tier is a colour and a mark, never colour alone: colour-blind readers and grayscale printouts both have to survive it. Tier movement toward GREEN requires a new primary document in hand — not more plausibility, not a second outlet, not greater confidence.

Connectors — the three layers

Politics is filed on three layers, and each has a different filing system. The gap between them is where things hide: local candidate money is filed at the county Board of Elections and appears in no API at all — not FEC, not the state system. That gap is closed by a records request, not a connector, which is why every county in the seed set now carries a Board of Elections row.

Evidence & provenance

Every module — the records atlas, the montage engine, the vulnerability desk, the connectors — writes one shape of provenance record into one append-only ledger. That shared shape is what lets a rendered video, a CVE report, and a received record all be indexed by the same evidence database.

The contract, in one line.
The database says what a file is and that it is intact. evidence/ holds the bytes. sentinel prov verify proves the two still agree — it recomputes every ledger line's self-hash and names any line edited after it was written.
Paths are stored relative, never absolute. An absolute path leaks your machine layout and breaks portability, so both the schema constraint sources_relative_path_only and the provenance spine refuse one.

The tools

One entry point. bin/sentinel dispatches to the module that owns each job, so there is one command to remember rather than six.
